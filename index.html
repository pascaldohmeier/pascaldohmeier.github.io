Die Apps

Pathfinder Memory

Ein Raster, versteckte Spiegel, eine Kugel. Präg dir ein, wo die Spiegel liegen — dann verschwinden sie, und du sagst voraus, an welchem Tor die Kugel wieder herauskommt. Jeden Tag ein neues Rätsel, weltweit dasselbe für alle.

Shingoki

Ein Schleifenrätsel auf einem Punktgitter. Weiße Kreise durchläuft die Schleife geradeaus, schwarze mit einem Knick, und die Zahl sagt, wie lang die beiden geraden Arme zusammen sind. Ein Tagesrätsel für alle, dazu unbegrenztes Üben in drei Größen. Gewertet wird die Zeit.

Hakoro

Ein Klotz, doppelt so hoch wie breit, rollt über seine Kanten. Er muss hochkant in ein Loch fallen, das genau eine Zelle groß ist — liegend passt er nicht. Endlos viele Level, für alle dieselben, dazu ein Tagesrätsel und ein Expertenmodus mit von Hand gebauten Brettern.
